## About

This project is the backend for [frontend](https://github.com/Kutsiy/ua-med-frontend)

## Stack

This project was built with the following technologies:

- NestJs
- Fastify
- Prisma
- Redis
- PostgreSQl
- GraphQL

## How to run

If you want to check how the project works, just clone this repo and run:

```bash
npm run start:dev
```
